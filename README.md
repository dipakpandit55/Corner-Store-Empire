# Corner Store Empire — Version 5

V5 adds Build Mode, placeable equipment, store expansion, improved progression, cleaner money formatting, customer queues, stocking, cashier automation, deliveries, spills/cleaning, and persistent saves.

## Controls
- WASD / Arrow keys: move
- E: interact
- Build Mode: choose equipment, then click/tap the floor to place it
- R: rotate selected equipment before placement
